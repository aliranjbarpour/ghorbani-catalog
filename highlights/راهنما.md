## روش گذاشتن در اینستاگرام
1. استوری‌های هر پوشه را **به ترتیب شماره** منتشر کنید (هایلایت به ترتیب زمان انتشار مرتب می‌شود).
2. پروفایل ← دکمه‌ی **+** (New) ← استوری‌های همان دسته را انتخاب کنید ← اسم هایلایت را بنویسید (مثلاً «طرح چوب»).
3. **Edit Cover** ← آیکون عکس ← `00-cover.jpg` همان پوشه را انتخاب کنید (اگر برش درست نبود، از `00-cover-square.jpg` استفاده کنید).
4. برای اضافه کردن استوری‌های بعدی: روی استوری بزنید ← **Highlight** ← هایلایت همان دسته.

## ساخت دوباره‌ی کاورها
با روشن بودن سرور (پورت 8080)، در پوشه‌ی `_work/render`:

```bash
node covers.mjs
```
طرح کاورها در `_work/highlights/cover.html` و فهرست دسته‌ها در `_work/highlights/list.json` است.
